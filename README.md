# ci-cd-final-project

This repository contains the template to be used for the Final Project for the Coursera course **CI/CD Tools and Practices**.

## Usage

This repository is intended to be used as a template to create your own repository in your GitHub account. There is no need to fork it, as it has been set up as a template. This avoids confusion when making pull requests in the future.

From the GitHub **Code** page, press the green **Use this template** button to create your own repository from this template.

Name your repository: `ci-cd-final-project`.

## Setup

After entering the lab environment, run the `setup.sh` script in the `./bin` folder to install the prerequisite software.

```bash
bash bin/setup.sh
```

Then exit the shell and start a new one for the Python virtual environment to be activated.

```bash
exit
```

## Tasks

Complete the GitHub Actions workflow, configure the Tekton tasks, and deploy the sample application using the OpenShift pipeline as instructed in the course labs.
